    אקדמיית Claude Code

    Claude Code ברמה הכי גבוהה, בעברית ובתרגול אמיתי

    Claude Code הוא סוכן תכנות שעובד בתוך הטרמינל, ה-IDE, הדפדפן וה-CI שלכם: קורא קוד, עורך קבצים, מריץ פקודות ופותח PR. הקורס הזה לוקח אתכם מההתקנה הראשונה ועד בניית סוכנים, אוטומציות ואינטגרציות משלכם.

    מפת הלמידה

    מתחיליםהתקנה, ממשק וקיצורים, ואיך עובדים נכון: לחקור, לתכנן, לבצע ולוודא.
    בינוניCLAUDE.md וזיכרון, הרשאות והגדרות, ניהול הקשר ופקודות מותאמות.
    מתקדמיםSkills, Subagents, Hooks, שרתי MCP ו-Plugins: להרחיב את Claude לכל צורך.
    מומחיםמצב headless ו-CI, Agent SDK, עבודה מקבילית ובענן, אבטחה ועלויות, ובניית מערכת שלמה.
    מאסטר40 טריקים של מקצוענים, 6 דוגמאות מלאות מקצה לקצה וספריית פרומפטים מוכנים.
    סודות מתקדמיםשרת MCP משלכם, לולאות אוטונומיות, צוות סוכנים, Hooks ברמת מאסטר, בוט SDK, סוכני לילה, ניטור ארגוני, מדריך פקודות מלא, חדר הסודות ופיתוח פרויקטים מלאים.
    אינטגרציות ופרויקטים11 מתכוני אינטגרציה, בונה אינטגרציות לצוות, פרויקט מלא אמיתי שנבנה ונבדק, ותרחישי החלטה.
    ארגז הכלים של המומחהחבילה של 25 פקודות, 8 סוכנים ו-6 Skills עם סקריפט התקנה, 16 דפוסי פרומפט ובונה פרומפטים, גלריית התאמה אישית ופרוטוטייפ מהיר עם מחולל חי.
    מצגות6 מצגות שמסכמות את הקורס, עם מסך מלא. מתאימות גם להצגה לצוות.
    סדנת תרגולסימולטור (20 משימות), מחוללים, מחולל פרויקט מלא, מעבדת פרומפטים, אתגרים, כרטיסיות, פרויקט גמר, בודק הגדרות, מילון ואתגר יומי.
    מבחן גמר15 שאלות אקראיות מכל הקורס. עוברים ב-80% ומקבלים תעודה על המסך.

    איך להפיק מהקורס את המקסימום

    • כל פרק נגמר בבוחן קצר. תשובה נכונה על כל הבוחן מסמנת את הפרק כהושלם ומעניקה XP.
    • פתחו את Claude Code בטרמינל ליד הקורס ונסו כל דוגמה על פרויקט אמיתי. כל בלוק קוד כולל כפתור העתקה.
    • ב"מחוללים" אפשר ליצור בכמה לחיצות קבצי הגדרות מוכנים: הרשאות, Hooks, Subagents, Skills, MCP ו-CLAUDE.md.
    • ההתקדמות נשמרת בדפדפן הזה. כתובת כל פרק נשמרת בשורת הכתובת, אז אפשר לשמור סימנייה לפרק.

    "הרץ את הבדיקות והלינטר, תקן מה שנכשל, ואז צור commit עם הודעה ברורה ופתח PR."

    שבעה כללי זהב לפרומפטים

    1. ספציפי עדיף על קצר: שמות קבצים, פונקציות, הודעת השגיאה המלאה, ומה ייחשב הצלחה.

    3. הצביעו על דוגמה קיימת: "בנה את זה כמו @src/widgets/Calendar.tsx".
    4. תמונות: הדביקו צילומי מסך של שגיאות או של עיצוב.

    # Project: Shop API

## Commands
- `pnpm dev` – start dev server on :3000
- `pnpm test -- path/to/file` – run a single test file (prefer this over the full suite)
- `pnpm lint --fix` – lint and autofix

## Architecture
- `src/routes` HTTP handlers only, no business logic
- `src/services` business logic, pure where possible
- DB access only through `src/db/repo.ts`

## Conventions
- TypeScript strict, no `any`
- Money is integer agorot, never floats
- IMPORTANT: never edit files in `src/generated/`

## Workflow
- Run typecheck and the related tests after every change
- Branch names: `feat/...`, `fix/...`

See @docs/api-conventions.md for error format.

    עקרונות כתיבה

    • קצר וממוקד: כל שורה נטענת בכל סשן ועולה טוקנים. מה שלא משנה התנהגות, מוחקים.
    • פקודות מדויקות בבלוקי קוד, כולל איך מריצים בדיקה אחת.
    • הדגשה: IMPORTANT או YOU MUST לכללים קריטיים. השתמשו בזה במשורה.
    • ייבוא: @path/to/file.md מושך קובץ נוסף, כך שהקובץ הראשי נשאר קצר.
    • תחזוקה: כש-Claude טועה באותו דבר פעמיים, בקשו ממנו "הוסף כלל ל-CLAUDE.md כדי שזה לא יקרה שוב".
    • שיפור: מדי פעם בקשו "עבור על CLAUDE.md, קצר אותו והסר כפילויות".
    מה לא שמים ב-CLAUDE.mdסודות, מפתחות API, תיעוד ארוך שאפשר לקשר אליו, וכללי סגנון שהלינטר כבר אוכף. בשביל אכיפה קשיחה משתמשים ב-Hooks (פרק מתקדמים).

    Hooks: כללים שתמיד מתקיימים

    הנחיה ב-CLAUDE.md היא בקשה, ו-Hook הוא חוק. Hook הוא פקודת shell שרצה אוטומטית באירוע מסוים: לפני כלי, אחרי כלי, כשנשלח פרומפט, כש-Claude מסיים ועוד.

    האירועים

    אירועמתישימוש טיפוסי
    PreToolUseלפני הרצת כליחסימת פקודות מסוכנות או עריכת קבצים מוגנים
    PostToolUseאחרי שכלי הצליחפורמט אוטומטי, לינט, בדיקות
    UserPromptSubmitכשהמשתמש שולח הודעההוספת הקשר (ענף, טיקט), חסימת סודות בפרומפט
    Notificationכש-Claude מחכה לאישור או לקלטהתראה בשולחן העבודה או בטלפון
    Stop / SubagentStopכשהסוכן מסיים תשובההרצת בדיקות ודרישה להמשיך אם נכשלו
    SessionStart / SessionEndפתיחה וסגירה של סשןטעינת הקשר, התקנת תלויות, ניקוי
    PreCompactלפני סיכום ההקשרגיבוי ה-transcript

    איך זה עובד

    • ה-Hook מקבל ב-stdin אובייקט JSON עם פרטי האירוע (tool_name, tool_input, session_id ועוד).
    • קוד יציאה 0: הכול תקין. קוד יציאה 2: חסימה, וה-stderr נשלח ל-Claude כהסבר. כל קוד אחר: שגיאה שמוצגת למשתמש בלבד.
    • אפשר גם להחזיר JSON ב-stdout עם החלטה מפורטת: ב-PreToolUse השדה permissionDecision מקבל allow, deny, ask או defer, ואפשר גם updatedInput כדי לשנות את הקלט לכלי.
    • סוגי Hooks: מלבד command יש גם http (קריאה ל-URL), mcp_tool, prompt (שאלה למודל) ו-agent. יש 33 אירועים בסך הכול, כולל PostCompact, FileChanged, WorktreeCreate ו-PermissionDenied.
    • $CLAUDE_PROJECT_DIR מצביע לשורש הפרויקט, כדי להריץ סקריפטים בנתיב יציב.

If every task is ticked: write DONE to STATUS and stop." \
    --permission-mode acceptEdits \
    --allowedTools "Read,Edit,Write,Glob,Grep,Bash(npm test *),Bash(npm run lint *),Bash(git add *),Bash(git commit *)" \
    --max-turns 40
  grep -qx DONE STATUS 2>/dev/null && { echo "all done"; break; }
done

  '{hookSpecificOutput:{hookEventName:"PreToolUse",permissionDecision:$d,permissionDecisionReason:$r}}'; exit 0; }
# read-only commands: approve

exit 0   # everything else: normal permission flow

    בוט טלגרם שמתקן באגים: Agent SDK בפועל

    שולחים לבוט "הכפתור שמירה לא עובד בעמוד ההגדרות", והוא חוקר את הקוד, מתקן, מריץ בדיקות, פותח PR ומחזיר קישור. כ-60 שורות קוד.

    import os, asyncio
from telegram import Update
from telegram.ext import Application, MessageHandler, ContextTypes, filters
from claude_agent_sdk import query, ClaudeAgentOptions

ALLOWED = {int(x) for x in os.environ["ALLOWED_CHAT_IDS"].split(",")}   # who may use the bot
REPO = os.environ["REPO_DIR"]
lock = asyncio.Lock()                                                    # one job at a time

OPTIONS = ClaudeAgentOptions(
    cwd=REPO,
    permission_mode="acceptEdits",
    max_turns=60,
    allowed_tools=["Read", "Edit", "Write", "Glob", "Grep",
                   "Bash(npm test *)", "Bash(git checkout -b *)", "Bash(git add *)",
                   "Bash(git commit *)", "Bash(git push -u origin *)", "Bash(gh pr create *)"],
    append_system_prompt=("You fix bugs reported by teammates. Always: create a branch "
                          "bot/<short-name>, reproduce with a test, fix, run tests, push, "
                          "open a PR, and end your answer with the PR URL."),
)

async def handle(update: Update, ctx: ContextTypes.DEFAULT_TYPE):
    if update.effective_chat.id not in ALLOWED:
        return
    if lock.locked():
        await update.message.reply_text("עובד על משימה אחרת, נסו בעוד כמה דקות")
        return
    async with lock:
        await update.message.reply_text("קיבלתי, מתחיל לעבוד…")
        final = ""
        async for m in query(prompt=update.message.text, options=OPTIONS):
            if type(m).__name__ == "ResultMessage":
                final = getattr(m, "result", "") or ""
        await update.message.reply_text(final[-3500:] or "סיימתי, בלי תוצאה טקסטואלית")

app = Application.builder().token(os.environ["TELEGRAM_TOKEN"]).build()
app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, handle))
app.run_polling()

const ALPHABET = "abcdefghijkmnpqrstuvwxyz23456789"; // 32 chars, no look-alikes

export function makeCode(len = 7) {
  return Array.from(randomBytes(len), (b) => ALPHABET[b % ALPHABET.length]).join("");
}

export function isValidUrl(s: string) {
  try {
    const u = new URL(s);
    return u.protocol === "https:" || u.protocol === "http:";
  } catch {
    return false;
  }
}

export function buildApp(db: Database) {
  const app = Fastify();
  const insert = db.prepare("INSERT INTO links (code, url) VALUES (?, ?)");
  const find = db.prepare("SELECT url FROM links WHERE code = ?");
  const hit = db.prepare("UPDATE links SET clicks = clicks + 1 WHERE code = ?");
  const stats = db.prepare("SELECT code, url, clicks, created_at FROM links WHERE code = ?");

  app.post<{ Body: { url?: string } }>("/api/links", async (req, reply) => {
    const url = req.body?.url ?? "";
    if (!isValidUrl(url)) {
      return reply.code(400).send({ code: "invalid_url", message: "url must be http(s)" });
    }
    for (let attempt = 0; attempt < 5; attempt++) {
      const code = makeCode();
      try {
        insert.run(code, url);
        return reply.code(201).send({ code, short: `/${code}` });
      } catch (e) {
        if ((e as { code?: string }).code !== "SQLITE_CONSTRAINT_PRIMARYKEY") throw e;
      }
    }
    return reply.code(503).send({ code: "busy", message: "try again" });
  });

  app.get<{ Params: { code: string } }>("/api/links/:code", async (req, reply) => {
    const row = stats.get(req.params.code);
    return row ?? reply.code(404).send({ code: "not_found", message: "no such link" });
  });

  app.get<{ Params: { code: string } }>("/:code", async (req, reply) => {
    const row = find.get(req.params.code) as { url: string } | undefined;
    if (!row) return reply.code(404).send({ code: "not_found", message: "no such link" });
    hit.run(req.params.code);
    return reply.redirect(row.url, 302);
  });

  return app;
}
