# מאסטר בלוקי קוד – קורס מתקדם ואינטראקטיבי

קורס בעברית לשימוש מקצועי בבלוקי קוד ב-Markdown ובאינטגרציות הנפוצות.

## הפעלה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או ב-build (צריך חיבור לאינטרנט לספריות התצוגה).

## תוכן

| פרק | נושא |
|---|---|
| 0 | פתיחה ומפת הקורס |
| 1 | יסודות: inline, גדרות, הזחה וכללי CommonMark |
| 2 | הדגשת תחביר ומזהי שפה (`console` מול `bash`, `jsonc`, `text`) |
| 3 | טכניקות מתקדמות: גדרות מקוננות, רשימות, `diff`, info string, RTL |
| 4 | GitHub ו-GitLab: `suggestion`, mermaid, geojson, stl, math, permalinks, `<details>` |
| 5 | Docusaurus, MkDocs Material, VitePress, Jupyter, Quarto |
| 6 | Slack, Discord (`ansi`), Teams, Notion, Obsidian, Jira, VS Code, markdownlint |
| 7 | בלוקי קוד בעבודה עם Claude ומודלי שפה, כולל חילוץ בלוקים בקוד |
| 8 | מגרש משחקים חי עם הדגשת תחביר ו-Mermaid |
| 9 | אתגרים שנבדקים אוטומטית וצ'קליסט מקצועי |

כל פרק כולל בוחן. ההתקדמות נשמרת בדפדפן (localStorage).
