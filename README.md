# אקדמיית Claude Code

קורס אינטראקטיבי בעברית ל-Claude Code, ממתחילים ועד מומחים, עם סדנת תרגול ומבחן גמר.

## הפעלה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה. ההתקדמות נשמרת בדפדפן.

## מבנה

| רמה | פרקים |
|---|---|
| מתחילים | התקנה וכניסה ראשונה · ממשק, קיצורים ופקודות · זרימת עבודה ופרומפטים |
| בינוני | CLAUDE.md וזיכרון · הרשאות, מצבים והגדרות · ניהול הקשר ונקודות שמירה · פקודות מותאמות |
| מתקדמים | Skills · Subagents · Hooks · MCP ואינטגרציות (קטלוג לפי צורך) · Plugins, Output Styles, Status Line |
| מומחים | Headless ו-CI/CD · Agent SDK · עבודה מקבילית וענן · אבטחה, עלויות ומודלים · מפת פיצ'רים להרחבה |
| סדנת תרגול | סימולטור טרמינל (12 משימות) · מחוללים (CLAUDE.md, הרשאות, Hooks, Subagent, פקודה/Skill, MCP) · 6 אתגרים שנבדקים אוטומטית · כרטיסיות עם חזרה מרווחת |
| מבחן גמר | 15 שאלות אקראיות, מעבר ב-80%, תעודה |

XP, דרגות וימי רצף מתעדכנים לאורך הלמידה.

## קבצים

- `src/claude-code-course.html` – המקור (גם הגרסה שמתפרסמת כ-Artifact)
- `index.html` – גרסה עצמאית, נבנית עם `./build.sh`
- `code-blocks.html` – קורס משלים על בלוקי קוד ב-Markdown ובאינטגרציות
