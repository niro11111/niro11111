# אקדמיית Claude Code

קורס אינטראקטיבי בעברית ל-Claude Code, ממתחילים ועד מומחים, עם סדנת תרגול ומבחן גמר.

## הפעלה

- **באתר**: ‏https://niro11111.github.io/niro11111/ (אחרי הפעלה חד-פעמית של GitHub Pages, ראו למטה). אפשר להתקין כאפליקציה, והיא עובדת גם בלי אינטרנט.
- **מקומית**: פותחים את `index.html` בדפדפן.
- **ב-claude.ai**: הגרסה עם המורה וסנכרון בין מכשירים.

### הפעלת האתר (פעם אחת)

1. במאגר ב-GitHub: ‏Settings ← Pages ← Source: **GitHub Actions**.
2. ‏Actions ← Deploy website ← Run workflow (או כל push לענף).

מאז כל push מעדכן את האתר אוטומטית. ה-workflow בודק קודם אם Pages מופעל, ואם לא, הוא מדלג בלי להיכשל.

XP, דרגות וימי רצף מתעדכנים לאורך הלמידה. מסלולי למידה לפי תפקיד, הערות אישיות לכל פרק, 18 הישגים, חיפוש בכל הקורס עם Ctrl+K, כפתור "הפתיעו אותי", וכמה ביצי הפתעה נסתרות.

בגרסה שמתפרסמת ב-claude.ai יש גם מורה AI בכל פרק ("שאל את המורה" וכפתור "הסבר" על כל בלוק קוד) וסנכרון התקדמות בין מכשירים. בגרסה המקומית (`index.html`) שני אלה מוסתרים.

## יכולות מערכת

- **לוח בקרה**: המשך מאיפה שעצרתם, הצעד המומלץ הבא, התקדמות לפי רמה, חזרה חכמה על טעויות, מבחן מיון, וגיבוי ושחזור (קוד טקסט).
- **סנכרון מלא** בין מכשירים בגרסת claude.ai: כל הנתונים מסונכרנים (התקדמות, הערות, מסלול, מראה, ערכת צבעים, נקודת המשך). מה שגדל (XP, הישגים) מתמזג, ומה שעורכים או מבטלים (הערות, צ'קליסטים, הגדרות) הולך לפי השינוי האחרון. מחיקות ואיפוס מסונכרנים, ושמירה בו-זמנית משני מכשירים לא דורסת.
- **מנתח פרויקטים**: גוררים קבצי הגדרה של פרויקט ומקבלים CLAUDE.md, הרשאות, Hooks, שרתי MCP מומלצים, סוכן ופקודה. הניתוח קורה בדפדפן בלבד.
- **מראה**: 7 ערכות עיצוב (כולל ניגודיות גבוהה ורטרו סודי), גודל טקסט ומצב קומפקטי, מסונכרנים בין מכשירים.
- **חדר הסודות**: 30 פיצ'רים נסתרים שנפתחים עם XP.
- **נגישות ומקלדת**: קישור דילוג, מיקוד כותרת במעבר פרק, ומסך קיצורים (`?`), ‏Ctrl+K, ‏Alt+חצים, G ואז D/S.

## השרת: backend, frontend ומסד נתונים

לאקדמיה יש שרת משלה (`server/`): ‏Node.js עם Fastify, ומסד נתונים SQLite. השרת מגיש את אפליקציית הווב, ומוסיף חשבונות, סנכרון לשרת ותעודות עם קישור אימות. כשהאפליקציה רצה מהשרת היא מזהה אותו לבד ומציגה "👤 התחברות וסנכרון". ב-claude.ai, כקובץ HTML וב-GitHub Pages היא ממשיכה לעבוד בדיוק כמו קודם.

### הפעלה

```bash
./build.sh                      # בונה את האתר ל-site/
cd server && npm ci && npm start   # http://localhost:8080
```

ב-production עם Docker (מסד הנתונים והגיבויים ב-volume):

```bash
docker compose up -d --build    # או: fly launch --no-deploy && fly volumes create academy_data && fly deploy
```

כל ההגדרות, עם הסבר לכל אחת, נמצאות ב-`.env.example`. לכל הגדרה יש ברירת מחדל בטוחה, וערך לא תקין עוצר את השרת עם הודעה ברורה.

### מה יש בשרת

| תחום | מה נבנה |
|---|---|
| חשבונות | הרשמה, התחברות, התנתקות, שינוי שם, החלפת סיסמה (מנתקת מכשירים אחרים), רשימת התחברויות וניתוק מכשירים אחרים |
| סיסמאות | ‏scrypt עם salt לכל משתמש (אסינכרוני, לא חוסם), השוואה בזמן קבוע, ואותו זמן תגובה גם כשהאימייל לא קיים |
| sessions | טוקן אקראי של 256 ביט בעוגייה `HttpOnly`, ‏`SameSite=Lax` ו-`Secure` ב-production. במסד נשמר רק ה-hash של הטוקן. תוקף מתחדש בשימוש |
| הגנות | ‏CSRF (כותרת חובה ובדיקת Origin), הגבלת קצב כללית ו-10 בדקה להתחברות, נעילת חשבון אחרי 10 ניסיונות כושלים, ולידציה קשיחה עם zod (שדות לא מוכרים נדחים), מגבלת גודל לבקשות, שגיאות בלי stack traces |
| כותרות אבטחה | ‏CSP קשיח עם hash של הסקריפט (בלי `unsafe-inline` לסקריפטים), ‏`frame-ancestors 'none'`, ‏HSTS ב-production, ‏nosniff ו-Referrer-Policy |
| סנכרון | אותו מנגנון מיזוג של האפליקציה, עם concurrency אופטימי: אם מכשיר אחר שמר בינתיים, השרת מחזיר 409 עם הגרסה החדשה, והאפליקציה ממזגת ושומרת. שום שינוי לא נדרס |
| פרטיות | ייצוא כל המידע האישי ב-JSON, ומחיקת חשבון עם כל השורות במסד. במחשב משותף, התנתקות מנקה את העותק המקומי, וחשבון אחר לא יורש את ההתקדמות של הקודם |
| תעודות | ‏מונפקות רק כשההתקדמות בשרת מראה מבחן גמר שעבר. דף אימות ציבורי ב-`/verify/<id>` (מזהה אקראי, כל קלט מקודד ל-HTML) |
| תפעול | ‏`/healthz` ו-`/readyz`, לוגים מובנים בלי עוגיות, כיבוי מסודר, migrations ממוספרים, WAL, גיבויים אונליין תקופתיים (`npm run backup`), ניקוי sessions שפגו, דחיסה (790KB ← 259KB), ‏cache נכון לכל סוג קובץ |
| ניהול | ‏`/api/admin/stats` למיילים שב-`ADMIN_EMAILS` בלבד |
| Docker | ‏multi-stage, משתמש לא-root, ‏HEALTHCHECK, ‏volume לנתונים. ‏compose מריץ את הקונטיינר read-only עם `no-new-privileges` |

### AI בשרת שלכם

כשמגדירים `ANTHROPIC_API_KEY` ו-`AI_MODEL`, המורה ה-AI וכל יכולות ה-AI (שיפור פרומפטים, שאלות חדשות, אבחון שגיאות ו-`ai review` בטרמינל הקוד) עובדים גם בשרת שלכם, ולא רק ב-claude.ai. השרת קורא ל-Claude API דרך ה-SDK הרשמי עם streaming. המפתח לא מגיע לדפדפן, לכל משתמש יש מכסה יומית ותקרת טוקנים, והשימוש נשמר במסד. כשיש בקשה עם כלים, הדפדפן מריץ את הכלים (למשל קריאת הקבצים שהעליתם) ושולח את התוצאות חזרה. בלי מפתח, ה-AI פשוט מוסתר.

### אוטומציה עם Make (או Zapier ו-n8n)

- **אירועים יוצאים**: ‏`WEBHOOK_URL` מקבל `user.registered`, ‏`progress.milestone`, ‏`certificate.issued` ו-`user.deleted`, עם חתימת HMAC ב-`x-cca-signature`. השליחה ברקע עם retries, ולא מעכבת אף בקשה. אימייל נשלח רק עם `WEBHOOK_INCLUDE_PII=true`.
- **API לקריאה**: ‏`/api/integrations/stats` ו-`/api/integrations/certificates?since=` עם `Authorization: Bearer $INTEGRATION_TOKEN`.
- בפרק "Make.com עם Claude ו-Claude Code" יש מחוללים מוכנים ושישה תרחישים מלאים.

### API

| שיטה | נתיב | |
|---|---|---|
| POST | `/api/auth/register` · `/api/auth/login` · `/api/auth/logout` | חשבון |
| GET · PATCH · DELETE | `/api/me` | פרופיל, שינוי שם, מחיקת חשבון (עם סיסמה) |
| POST | `/api/auth/password` | החלפת סיסמה |
| GET | `/api/me/export` · `/api/me/sessions` | ייצוא המידע, התחברויות |
| POST | `/api/me/logout-others` | ניתוק מכשירים אחרים |
| GET · PUT | `/api/progress` | סנכרון התקדמות |
| POST · GET | `/api/certificates` · `/api/certificates/:id` | הנפקה ואימות |
| GET | `/verify/:id` · `/healthz` · `/readyz` · `/api/admin/stats` | דף אימות, בריאות, סטטיסטיקה |

כל בקשה שמשנה משהו צריכה את הכותרת `x-cca: 1` ו-JSON.

## בדיקות

**הכול בפקודה אחת:** `tests/run-all.sh` (בונה ומריץ את כל הבדיקות).

- `node tests/e2e-complete-course.js` – משלים את כל 69 הפרקים בדרך האמיתית של כל אחד (בחנים, אתגרים, פרויקטים, תרחישים, ספידראן ומבחן גמר) ובודק 100%, תעודה, ושכל 57 פקודות הסימולטור עונות.
- `cd server && npm test` – ‏50 בדיקות API (כולל webhooks חתומים עם retries, ‏API האינטגרציה ושער ה-AI מול Claude API מדומה): חשבונות, ‏CSRF, הגבלות קצב ונעילה, הפרדה בין משתמשים, 409 בסנכרון, תעודות כולל XSS, ייצוא ומחיקה, ‏path traversal, גיבוי ודחיסה.
- `node tests/e2e-fullstack.js` – השרת האמיתי עם מסד זמני ושני דפדפנים כשני מכשירים: הרשמה, סנכרון בין מכשירים, שינויים בו-זמניים, תעודה ודף אימות, ייצוא, מחשב משותף, מחיקת חשבון, ובלי הפרות CSP.
- `node tests/e2e-ai-gateway.js` – השרת עם Claude API מדומה ודפדפן אמיתי: המורה, שאלות AI כ-JSON, ו-`ai review` עם לולאת כלים מלאה.
- `node tests/e2e-make.js` – פרק Make: כל המחוללים, וה-Hook שנוצר רץ באמת מול שרת שמחקה webhook של Make.
- `node tests/xss-fuzz.js` – מזריק קוד זדוני לכל שדה בכל 69 הפרקים, לוחץ על הכפתורים ובודק שדבר לא רץ ושלא נוצר HTML מהקלט.
- `node tests/a11y-axe.js` – בדיקת נגישות עם axe-core (כללי WCAG) על כל הפרקים, במצב בהיר וכהה.
- `node tests/monkey.js [seed] [steps]` – אלפי פעולות אקראיות עם seed קבוע (אפשר לשחזר כל כשל).
- `cd server && npm test` כולל גם מקרי קצה: הרשמה כפולה בו-זמנית, ‏Unicode, ניסיונות prototype pollution, גוף גדול מדי ו-Origin משונים.
- `node tests/contrast.js` – ניגודיות WCAG ‏(4.5:1) בכל 7 הערכות, במצב בהיר וכהה.
- `node tests/audit-buttons.js` – לוחץ על כל כפתור בכל פרק ומדווח על כפתורים בלי השפעה ועל שגיאות.
- `node tests/e2e-toolbox.js [dir]` – חבילת הפקודות (שומר את סקריפט ההתקנה ב-dir/packtest), בונה הפרומפטים, הגלריה, מחולל הפרוטוטייפים וערכות העיצוב.
- `node tests/e2e-sync-full.js` – שני מכשירים מדומים: העברה מלאה, מחיקה חיה, שמירה בו-זמנית, איפוס, מצב גלישה פרטית ודחיית המורה.
- `node tests/validate-pack.js` – מריץ את סקריפט ההתקנה של חבילת המומחה ובודק את כל 39 הקבצים.
- `node tests/e2e-pwa.js` – מגיש את site/ מקומית ובודק manifest, אייקונים, ‏service worker, פתיחה בלי אינטרנט והודעת עדכון.
- `node tests/e2e-dashboard-sync.js` – לוח בקרה, טעויות, מבחן מיון, גיבוי, סנכרון חי (עם יכולות מדומות) ומנתח הפרויקטים.

כולם דורשים Playwright, ומריצים אותם אחרי `./build.sh` (שבודק גם שהסקריפט של הדף תקין תחבירית).

הפקודות, הדגלים, אירועי ה-Hooks וקיצורי המקלדת נבדקו מול התיעוד הרשמי של Claude Code בנובמבר 2026.
