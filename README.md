# אקדמיית Claude Code

קורס אינטראקטיבי בעברית ל-Claude Code, ממתחילים ועד מומחים, עם סדנת תרגול ומבחן גמר.

## הפעלה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה. ההתקדמות נשמרת בדפדפן.

## מבנה

| רמה | פרקים |
|---|---|
| מתחילים | התקנה וכניסה ראשונה · ממשק, קיצורים ופקודות · זרימת עבודה ופרומפטים |
| בינוני | CLAUDE.md וזיכרון · הרשאות, מצבים והגדרות · ניהול הקשר ונקודות שמירה · פקודות מותאמות |
| מתקדמים | Skills · Subagents · Hooks · MCP ואינטגרציות (קטלוג לפי צורך) · Plugins, Output Styles, Status Line |
| מומחים | Headless ו-CI/CD · Agent SDK · עבודה מקבילית וענן · אבטחה, עלויות ומודלים · מפת פיצ'רים להרחבה |
| מאסטר | 40 טריקים של מקצוענים עם דוגמאות · 6 דוגמאות מקצה לקצה (Sentry, Figma, היכרות עם קוד, מיגרציה, ריוויו אוטומטי, אירוע production) · ספריית 33 פרומפטים |
| סודות מתקדמים | בניית שרת MCP משלכם · לולאות אוטונומיות · Claude שמנהל צוות סוכנים · Hooks ברמת מאסטר · בוט טלגרם עם Agent SDK · סוכני לילה מתוזמנים · ניתוח ההיסטוריה שלכם · ניטור ומדיניות ארגונית · שימושים שאינם קוד · מדריך פקודות מלא (103 פקודות, דגלים, משתנים והגדרות) · חדר הסודות (20 פיצ'רים נסתרים שנפתחים עם XP) · פיתוח פרויקטים מלאים (שיטה ב-10 שלבים ו-6 תוכניות) |
| אינטגרציות ופרויקטים | 11 מתכוני אינטגרציה (GitHub, Jira/Linear, Slack, Sentry, Figma, DB, Vercel, K8s, AWS, Grafana, Notion) · בונה אינטגרציות לצוות (.mcp.json, הרשאות, Slack hooks, /ticket, /ship) · פרויקט "קיצור" מלא שנבנה ונבדק (examples/kitzur) · תרחישי החלטה |
| מצגות | 6 מצגות מובנות עם מסך מלא וניווט במקלדת |
| סדנת תרגול | ספידראן 60 שניות · מחולל פרויקט מלא (PLAN, CLAUDE.md, הגדרות, פרומפטים ו-loop.sh) · מעבדת פרומפטים עם ציון · סימולטור עם 20 משימות · פרויקט גמר מודרך (10 שלבים) · בודק הגדרות · מילון, אתגר יומי והמחברת שלי · סימולטור טרמינל (12 משימות) · מחוללים (CLAUDE.md, הרשאות, Hooks, Subagent, פקודה/Skill, MCP) · 6 אתגרים שנבדקים אוטומטית · כרטיסיות עם חזרה מרווחת |
| מבחן גמר | 15 שאלות אקראיות, מעבר ב-80%, תעודה |

XP, דרגות וימי רצף מתעדכנים לאורך הלמידה. מסלולי למידה לפי תפקיד, הערות אישיות לכל פרק, 18 הישגים, חיפוש בכל הקורס עם Ctrl+K, כפתור "הפתיעו אותי", וכמה ביצי הפתעה נסתרות.

בגרסה שמתפרסמת ב-claude.ai יש גם מורה AI בכל פרק ("שאל את המורה" וכפתור "הסבר" על כל בלוק קוד) וסנכרון התקדמות בין מכשירים. בגרסה המקומית (`index.html`) שני אלה מוסתרים.

## קבצים

- `src/claude-code-course.html` – המקור (גם הגרסה שמתפרסמת כ-Artifact)
- `index.html` – גרסה עצמאית, נבנית עם `./build.sh`
- `code-blocks.html` – קורס משלים על בלוקי קוד ב-Markdown ובאינטגרציות
