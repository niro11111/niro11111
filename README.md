# אקדמיית Claude Code

קורס אינטראקטיבי בעברית ל-Claude Code, ממתחילים ועד מומחים, עם סדנת תרגול ומבחן גמר.

## הפעלה

- **באתר**: ‏https://niro11111.github.io/niro11111/ (אחרי הפעלה חד-פעמית של GitHub Pages, ראו למטה). אפשר להתקין כאפליקציה, והיא עובדת גם בלי אינטרנט.
- **מקומית**: פותחים את `index.html` בדפדפן.
- **ב-claude.ai**: הגרסה עם המורה וסנכרון בין מכשירים.

### הפעלת האתר (פעם אחת)

1. במאגר ב-GitHub: ‏Settings ← Pages ← Source: **GitHub Actions**.
2. ‏Actions ← Deploy website ← Run workflow (או כל push לענף).

מאז כל push מעדכן את האתר אוטומטית. ה-workflow בודק קודם אם Pages מופעל, ואם לא, הוא מדלג בלי להיכשל.

XP, דרגות וימי רצף מתעדכנים לאורך הלמידה. מסלולי למידה לפי תפקיד, הערות אישיות לכל פרק, 18 הישגים, חיפוש בכל הקורס עם Ctrl+K, כפתור "הפתיעו אותי", וכמה ביצי הפתעה נסתרות.

בגרסה שמתפרסמת ב-claude.ai יש גם מורה AI בכל פרק ("שאל את המורה" וכפתור "הסבר" על כל בלוק קוד) וסנכרון התקדמות בין מכשירים. בגרסה המקומית (`index.html`) שני אלה מוסתרים.

## יכולות מערכת

- **לוח בקרה**: המשך מאיפה שעצרתם, הצעד המומלץ הבא, התקדמות לפי רמה, חזרה חכמה על טעויות, מבחן מיון, וגיבוי ושחזור (קוד טקסט).
- **סנכרון מלא** בין מכשירים בגרסת claude.ai: כל הנתונים מסונכרנים (התקדמות, הערות, מסלול, מראה, ערכת צבעים, נקודת המשך). מה שגדל (XP, הישגים) מתמזג, ומה שעורכים או מבטלים (הערות, צ'קליסטים, הגדרות) הולך לפי השינוי האחרון. מחיקות ואיפוס מסונכרנים, ושמירה בו-זמנית משני מכשירים לא דורסת.
- **מנתח פרויקטים**: גוררים קבצי הגדרה של פרויקט ומקבלים CLAUDE.md, הרשאות, Hooks, שרתי MCP מומלצים, סוכן ופקודה. הניתוח קורה בדפדפן בלבד.
- **מראה**: 7 ערכות עיצוב (כולל ניגודיות גבוהה ורטרו סודי), גודל טקסט ומצב קומפקטי, מסונכרנים בין מכשירים.
- **חדר הסודות**: 30 פיצ'רים נסתרים שנפתחים עם XP.
- **נגישות ומקלדת**: קישור דילוג, מיקוד כותרת במעבר פרק, ומסך קיצורים (`?`), ‏Ctrl+K, ‏Alt+חצים, G ואז D/S.

## בדיקות

**הכול בפקודה אחת:** `tests/run-all.sh` (בונה ומריץ את כל הבדיקות).

- `node tests/e2e-complete-course.js` – משלים את כל 56 הפרקים בדרך האמיתית של כל אחד (בחנים, אתגרים, פרויקטים, תרחישים, ספידראן ומבחן גמר) ובודק 100%, תעודה, ושכל 57 פקודות הסימולטור עונות.
- `node tests/contrast.js` – ניגודיות WCAG ‏(4.5:1) בכל 7 הערכות, במצב בהיר וכהה.
- `node tests/audit-buttons.js` – לוחץ על כל כפתור בכל פרק ומדווח על כפתורים בלי השפעה ועל שגיאות.
- `node tests/e2e-toolbox.js [dir]` – חבילת הפקודות (שומר את סקריפט ההתקנה ב-dir/packtest), בונה הפרומפטים, הגלריה, מחולל הפרוטוטייפים וערכות העיצוב.
- `node tests/e2e-sync-full.js` – שני מכשירים מדומים: העברה מלאה, מחיקה חיה, שמירה בו-זמנית, איפוס, מצב גלישה פרטית ודחיית המורה.
- `node tests/validate-pack.js` – מריץ את סקריפט ההתקנה של חבילת המומחה ובודק את כל 39 הקבצים.
- `node tests/e2e-pwa.js` – מגיש את site/ מקומית ובודק manifest, אייקונים, ‏service worker, פתיחה בלי אינטרנט והודעת עדכון.
- `node tests/e2e-dashboard-sync.js` – לוח בקרה, טעויות, מבחן מיון, גיבוי, סנכרון חי (עם יכולות מדומות) ומנתח הפרויקטים.

כולם דורשים Playwright, ומריצים אותם אחרי `./build.sh` (שבודק גם שהסקריפט של הדף תקין תחבירית).

הפקודות, הדגלים, אירועי ה-Hooks וקיצורי המקלדת נבדקו מול התיעוד הרשמי של Claude Code בנובמבר 2026.

## קבצים

- `src/claude-code-course.html` – המקור (גם הגרסה שמתפרסמת כ-Artifact)
- `index.html` – גרסה עצמאית, נבנית עם `./build.sh`
- `web/` – שכבת האפליקציה: manifest, ‏service worker (עבודה בלי אינטרנט ועדכונים), אייקונים וכפתור התקנה
- `site/` – האתר המלא שנבנה (לא נשמר ב-git; נבנה ב-CI)
- `.github/workflows/pages.yml` – פריסה ל-GitHub Pages
- `code-blocks.html` – קורס משלים על בלוקי קוד ב-Markdown ובאינטגרציות
