# מדריך הפעלה: מה עושים אצלך כדי ש-JARVIS יעבוד במלואו

רוב המערכת רצה מיד. יש כמה דברים שרק את/ה יכול/ה לעשות, כי הם דורשים חשבון, מכשיר פיזי, מפתח או מחשב Mac. המדריך מסודר לפי סדר העדיפות.

---

## הדרך המהירה ביותר: אפליקציית ווב, בלי להתקין כלום

JARVIS המלא (המוח, 18 הסוכנים, זיכרון, כספים, אוטומציות ותזכורות) רץ גם כאתר רגיל בתוך הדפדפן, בלי שרת:

| איפה | מה מקבלים |
|---|---|
| **claude.ai** (הקישור שקיבלת) | הנתונים נשמרים בחשבון Claude שלך, פרטיים לך ובכל מכשיר. Claude הוא המוח, בלי מפתח API, ויכול לבצע פעולות דרך הכלים של JARVIS. יש ניתוח תמונות וייצוא קבצים. בתצוגה הזו המיקרופון של הדפדפן חסום, אז מכתיבים דרך מיקרופון המקלדת. התשובות מוקראות בקול. |
| **אתר עצמאי** (GitHub Pages או כל אחסון) | זיהוי דיבור בעברית עם בקשת הרשאת מיקרופון רגילה, התראות דפדפן ומזג אוויר. הנתונים נשמרים במכשיר. אפשר להוסיף מפתח Anthropic משלך בהגדרות כדי לקבל את Claude. |

**להפעיל את האתר העצמאי ב-GitHub Pages (פעם אחת, כ-2 דקות):**
1. ב-GitHub: המאגר `niro11111/niro11111` ← **Settings** ← **Pages** ← Source: **GitHub Actions**.
2. ‏**Actions** ← "JARVIS web app" ← **Run workflow**. ה-workflow בונה את האתר, מריץ את הבדיקות ומפרסם.
3. הכתובת תהיה `https://niro11111.github.io/niro11111/`. אפשר לפתוח אותה בכל מכשיר ו"להוסיף למסך הבית" בטלפון.

**בנייה ידנית:** `cd jarvis && npm install && npm run build:webapp`, ואז מעלים את התיקייה `dist/webapp` לכל אחסון סטטי (Netlify, Cloudflare Pages ודומיהם).

## שלב 1: להריץ את JARVIS על המחשב, עם שרת (5 דקות)

1. מתקינים Node.js בגרסה 20 ומעלה (https://nodejs.org).
2. בטרמינל:
   ```bash
   git clone https://github.com/niro11111/niro11111.git
   cd niro11111
   git checkout claude/jarvis-ai-system-spec-oxc6aq
   cd jarvis
   npm install
   npm start
   ```
3. פותחים בדפדפן את `http://127.0.0.1:7777`, ומדביקים את הטוקן שהודפס בטרמינל.
4. כדאי להשתמש ב-Chrome או ב-Edge, כי בהם עובד זיהוי הדיבור בעברית. מקש Alt+רווח מפעיל דיבור.

בשלב הזה הכול עובד על נתוני דמו: נתוני משפחה, בית חכם, משימות ואישורים.

## שלב 2: לחבר את "המוח" (Claude) כדי לקבל תשובות פתוחות ומחקר

בלי מפתח עובדות רק הפקודות המובנות (תדריך, כספים, בית חכם וכדומה). שאלות פתוחות ומחקר ברשת מחזירים הודעה ברורה שצריך מודל.

1. נכנסים ל-https://console.anthropic.com, יוצרים API Key, ומגדירים מגבלת הוצאה חודשית.
2. מפעילים מחדש:
   ```bash
   ANTHROPIC_API_KEY=sk-ant-... npm start
   ```
3. במסך "קונסולת מפתחים" רואים כמה קריאות היו, את זמני התגובה ואת העלות המשוערת.

## שלב 3: לחבר את הבית החכם האמיתי (Home Assistant)

1. ב-Home Assistant: פרופיל ← Long-Lived Access Tokens ← Create token.
2. מפעילים:
   ```bash
   HA_URL=http://homeassistant.local:8123 HA_TOKEN=... ANTHROPIC_API_KEY=... npm start
   ```
3. מכשירי Matter ו-MQTT מגיעים דרך Home Assistant. פתיחת מנעולים ונטרול אזעקה תמיד מחכים לאישור שלך.

## שלב 4: לחבר את Family Wealth OS האמיתי

כרגע מוצגים נתוני דמו (מסומנים "נתוני דמו"). כדי לחבר נתונים אמיתיים יש שתי אפשרויות:

- **ייבוא:** מוציאים את העסקאות מ-Family Wealth OS ושולחים אותן ל-`POST /api/wealth/import`. כל סכום הוא מספר שלם באגורות: `{"transactions":[{"date":"2026-11-01","description":"סופר","category":"groceries","amount":-35000}]}`.
- **חיבור ישיר:** אם ל-Family Wealth OS יש API, אפשר לבקש ממני לכתוב מתאם ב-`server/wealth`. לשם כך צריך לשלוח לי את תיעוד ה-API שלו.

ג׳ארוויס לעולם לא מעביר כסף, לא משקיע ולא רוכש. הוא רק מנתח וממליץ.

## שלב 5: אפליקציית הטלפון (iOS ו-Android)

הקוד נמצא ב-`jarvis/apps/mobile`. כאן הוא עבר בדיקת TypeScript ונבנתה ממנו חבילת Android.

1. מתקינים את אפליקציית **Expo Go** בטלפון.
2. במחשב:
   ```bash
   cd jarvis/apps/mobile
   npm install
   npx expo start
   ```
   סורקים את ה-QR עם הטלפון. הטלפון והמחשב צריכים להיות באותה רשת Wi-Fi.
3. ב-JARVIS בדפדפן: מרכז מכשירים ← רישום מכשיר, ובוחרים ios או android. מעתיקים את הטוקן (הוא מוצג פעם אחת בלבד).
4. באפליקציה מזינים את כתובת המחשב (למשל `http://192.168.1.10:7777`) ואת הטוקן.
5. כדי שהשרת יהיה נגיש מהטלפון, מפעילים אותו עם `JARVIS_HOST=0.0.0.0 npm start`, ורק ברשת הביתית.
6. בשביל התראות Push ובשביל גרסה לחנויות צריך חשבון Expo (חינם) ולהריץ `npx eas build`. ל-iOS צריך גם Apple Developer (99$ לשנה).

## שלב 6: השעונים

הקוד המקורי כתוב, אבל לא נבנה כאן: בשרת שלי אין Xcode ואין Android SDK.

- **Apple Watch:** צריך Mac עם Xcode 15 ומעלה. מעקב אחרי `jarvis/apps/watchos/README.md` (יוצרים פרויקט watchOS ומוסיפים את 4 הקבצים). אחרי ההתקנה רושמים מכשיר מסוג `watchos`.
- **Wear OS:** פותחים את `jarvis/apps/wearos` ב-Android Studio, מריצים על אמולטור או על שעון, ורושמים מכשיר מסוג `wearos`.
- נתוני בריאות כבויים כברירת מחדל. מפעילים אותם במרכז הפרטיות רק אם רוצים, והם לא נשלחים למודל השפה.

אם יופיעו שגיאות קומפילציה, שלחו לי אותן ואתקן. בלי הכלים האלה לא יכולתי לבנות את השעונים בעצמי.

## שלב 7: אפליקציית הדסקטופ (Windows / macOS)

הקוד ב-`jarvis/apps/desktop`. כאן הוא קומפל והורץ על Linux. בגרסה יש מגש מערכת, קיצור Ctrl+Shift+J (פתיחה וסגירה), Ctrl+Shift+Space (דיבור), והיא ממשיכה לרוץ ברקע.

1. מתקינים Rust (https://rustup.rs), ובנוסף ב-Windows את WebView2. ב-macOS הוא כבר מותקן.
2. ```bash
   cd jarvis/apps/desktop
   npx @tauri-apps/cli@2 build
   ```
   כך נוצר קובץ התקנה: ‎`.msi`/`.exe`‎ ב-Windows, או `.dmg` ב-macOS.
3. כדי ש-JARVIS יוכל לפתוח אפליקציות וקבצים, מפעילים את הגשר עם הרשאות מוגבלות:
   ```bash
   JARVIS_TOKEN=<הטוקן> JARVIS_ALLOWED_DIRS=~/Documents JARVIS_ALLOWED_APPS=calculator,code node desktop/bridge.js
   ```

## שלב 8: לגשת מחוץ לבית (לא חובה)

**לא** פותחים את פורט 7777 לאינטרנט. האפשרויות הבטוחות:

- Tailscale (VPN אישי, חינם): מתקינים במחשב ובטלפון, והכתובת עובדת מכל מקום.
- או Docker מאחורי HTTPS. יש `docker-compose.yml` בתיקייה, להריץ עם `JARVIS_TOKEN=... docker compose up -d`.

## שלב 9: אב־הטיפוס (prototypes)

גרסה מפורסמת לצפייה מיידית, גם מהטלפון ובלי להתקין כלום: https://claude.ai/artifact/WF8h24Xfz7hehn7vJBNGo5. הקישור פרטי, וכדי להראות אותו למישהו אחר צריך לשתף אותו מתפריט Share בעמוד.


- ‏`npm run build:prototypes` בונה את `prototypes/demo`. זו גרסה מלאה של הממשק שרצה בדפדפן בלי שרת, על תשובות שהוקלטו מהשרת האמיתי.
- ‏`prototypes/demo/devices.html` מציג את מסכי השעונים והטלפון.
