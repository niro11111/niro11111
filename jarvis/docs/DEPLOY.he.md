# הפעלת ג׳ארוויס בכתובת אמיתית

יש ארבע דרכים להפעיל את ג׳ארוויס. כולן מריצות את אותה מערכת: אותו מוח, אותן התממשקויות, אותו קול.

| דרך | כתובת | מתי מתאים |
|---|---|---|
| **1. קובץ HTML** (`jarvis.html`) | `file://` על המחשב | לחיצה כפולה ועובד. הנתונים נשמרים בדפדפן. |
| **2. שרת על המחשב** | `http://127.0.0.1:7777` | הגרסה המלאה: מסד נתונים SQLite, תזמונים, יומן, בנייה. |
| **3. השרת + מנהרה** | `https://xxxx.trycloudflare.com` | כתובת https אמיתית בחינם, בלי חשבון. מתחלפת בכל הפעלה. |
| **4. פריסה קבועה** | `https://jarvis.הדומיין-שלך` או `https://<שם>.onrender.com` / `.fly.dev` | כתובת קבועה 24/7 |

## 1. קובץ HTML

1. פותחים את `jarvis.html` ב-Edge או ב-Chrome.
2. הכל רץ בתוך הדף.

**קול:** ב-Edge יש קולות עבריים מובנים.

**שירותים חיצוניים:** שירותים שמאפשרים קריאה מדפדפן עובדים ישירות מהקובץ, למשל מטבע, קריפטו, זמני שבת, ויקיפדיה, טלגרם, Airtable ו-GitHub.

**חיבור לשרת:** בתוך הקובץ: **התממשקויות ← 🌐 כתובת וחיבור**. מזינים את כתובת השרת ואת טוקן הגישה. מאותו רגע הקובץ עובד מול השרת, עם אותם נתונים כמו במחשב ובטלפון.

## 2. שרת על המחשב: לחיצה כפולה

- **Windows:** `start-jarvis.bat`
- **Mac:** `start-jarvis.command`
- **Linux:** `./start-jarvis.sh`

הסקריפט:
1. בודק ש-Node.js 22 מותקן (https://nodejs.org).
2. מתקין רכיבים בפעם הראשונה.
3. מפעיל את השרת.
4. פותח את הדפדפן, כבר מחובר.
5. מדפיס את **טוקן הגישה**. משתמשים בו בטלפון, בקובץ ה-HTML ובכל מכשיר אחר.

אפשרויות:
- `--lan`: גישה מטלפון באותה רשת Wi-Fi. המיקרופון בטלפון דורש https, אז לשיחה קולית בטלפון השתמשו ב-`--public`.
- `--no-open`: בלי לפתוח דפדפן.

## 3. כתובת https ציבורית בחינם (Cloudflare Tunnel)

1. מתקינים פעם אחת את `cloudflared`:
   - **Windows:** `winget install --id Cloudflare.cloudflared`
   - **Mac:** `brew install cloudflared`
2. מריצים:
   ```
   start-jarvis.bat --public          (Windows)
   ./start-jarvis.sh --public         (Mac/Linux)
   npm run start:public               (כל מערכת)
   ```
3. הסקריפט מדפיס: `🌐 כתובת אמיתית: https://….trycloudflare.com`.
4. פותחים את הכתובת בכל מכשיר ובכל מקום ומתחברים עם הטוקן. המיקרופון והשיחה הקולית עובדים גם בטלפון, כי זו כתובת https.

**שימו לב:** הכתובת מתחלפת בכל הפעלה, וג׳ארוויס זמין רק כשהמחשב דולק. לכתובת קבועה: Cloudflare Tunnel עם חשבון ודומיין (חינם), או סעיף 4.

## 4. פריסה קבועה

### Docker על שרת משלכם, עם דומיין ו-HTTPS אוטומטי

1. מגדירים את הסודות:
   ```
   cp .env.example .env        # ממלאים JARVIS_TOKEN (openssl rand -hex 24) ומפתחות
   ```
2. מפנים את רשומת ה-DNS מסוג A של הדומיין לכתובת השרת.
3. מריצים:
   ```
   DOMAIN=jarvis.example.com docker compose --profile domain up -d
   ```
   Caddy מוציא תעודת Let's Encrypt לבד.

אותו דבר עם מנהרה חינמית במקום דומיין:
```
docker compose --profile public up -d
docker compose logs tunnel | grep trycloudflare
```

### Render

1. ב-Render: Dashboard ← New ← Blueprint, ובוחרים את המאגר. הקובץ `render.yaml` נמצא בשורש המאגר.
2. הכתובת: `https://jarvis-xxxx.onrender.com`.
3. הטוקן נוצר אוטומטית ומופיע ב-Environment.

**חשוב:** דיסק קבוע דורש תוכנית בתשלום. בתוכנית החינמית הנתונים מתאפסים בכל הפעלה מחדש.

### Fly.io

```
fly launch --no-deploy        # משאירים את fly.toml, משנים את שם האפליקציה
fly volumes create jarvis_data --size 1
fly secrets set JARVIS_TOKEN=$(openssl rand -hex 24)
fly deploy
```
הכתובת: `https://<שם>.fly.dev`.

## אבטחה

- **טוקן גישה:** כל ה-API דורש טוקן. אין עוגיות, ולכן כתובת ציבורית לא חושפת את הנתונים בלי הטוקן. שמרו את הטוקן כמו סיסמה.
- **הצפנה:** הגישה מבחוץ עוברת רק דרך HTTPS (מנהרה או Caddy). הפורט 7777 פתוח רק למחשב עצמו.
- **הגבלת קצב:** 300 בקשות לדקה למפתח, ו-30 לדקה ל-webhook נכנס.
- **CORS:** ברירת המחדל `*` מאפשרת לקובץ ה-HTML ולאפליקציה להתחבר. אפשר לצמצם עם `JARVIS_CORS=https://my.site,null`.
- **מפתחות שירותים:** נשמרים בשרת ולא מוחזרים לדפדפן. משתני סביבה גוברים על מה שנשמר בממשק.
- **בדיקה:** `GET /api/health` לבדיקות זמינות. ל-Docker מוגדר `HEALTHCHECK`.

## מה נבדק בפועל

| בדיקה | תוצאה |
|---|---|
| קובץ ה-HTML שנפתח מהמחשב (`file://`) מתחבר לשרת אמיתי | טוקן שגוי נדחה; משימה שנוצרה בקובץ נשמרה בשרת (`tests/e2e/ui.e2e.mjs`) |
| CORS: בקשה מקדימה, ודחייה בלי טוקן | נבדק (`tests/integrations.test.js`) |
| `scripts/start.mjs` | הפעיל שרת, הדפיס כתובת וטוקן, וזיהה ש-cloudflared לא מותקן |
| `docker compose config`, `render.yaml`, `fly.toml` | התחביר תקין |
| בניית ה-image ופריסה בפועל ל-Render/Fly | לא בוצעו: אין כאן Docker daemon, והפריסה דורשת את החשבון שלך |
