    איפה הגרש ההפוך (backtick) במקלדת?

    במקלדת אנגלית התו ` נמצא במקש שמשמאל ל-1, מעל Tab. בפריסה העברית אותו מקש מקליד ;, ולכן הרבה ישראלים "לא מוצאים" אותו.

    מערכתהדרך המהירה
    Windowsמחליפים לאנגלית (Alt+Shift או Win+Space), ולוחצים על המקש שמשמאל ל-1.
    macOSמחליפים לאנגלית (Ctrl+Space או מקש 🌐), ולוחצים על המקש שמשמאל ל-1 (או ליד Shift השמאלי, בחלק מהמקלדות האירופיות).
    Android / iOSבמקלדת האנגלית: מסך הסמלים (?123 ואז =\<), או לחיצה ארוכה על המקש של הגרש '.

    טריק לחיסכון בזמןבכל עורך שתומך בכך (VS Code, Obsidian, Notion, Espanso, AutoHotkey), הגדירו קיצור טקסט: מקלידים ;;; והוא הופך ל-```. אין צורך להחליף שפה בכלל.

    היסודות שכולם מפספסים

    1. קוד בתוך שורה (inline)

    עוטפים בגרש הפוך אחד (backtick). מתאים לשמות פונקציות, משתנים, פקודות קצרות ונתיבים.

    הריצו את `npm install` ואז ערכו את `config.json`.

    2. בלוק מגודר (fenced code block)

    שלושה גרשים הפוכים (או יותר) בשורה נפרדת, מיד אחריהם מזהה שפה, ושורת סגירה עם אותו תו. זו הדרך המומלצת כמעט תמיד.

    Markdown
    ```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

    אפשר להשתמש גם ב-tilde (~~~) במקום גרשים. זה שימושי כשהקוד עצמו מכיל גרשים הפוכים:

    ~~~bash
echo "the date is `date`"
~~~

        for i in range(3):
        print(i)

    בלוקי diff

    שורה שמתחילה ב-+ נצבעת בירוק, שורה שמתחילה ב-- נצבעת באדום. זה מעולה לקודי ריוויו ולמדריכי שדרוג.

    ```diff
 function total(items) {
-  return items.reduce((a, b) => a + b);
+  return items.reduce((a, b) => a + b, 0);
 }
```

    ב-GitHub אפשר גם לשלב diff עם הדגשת שפה בעזרת המזהה diff-js או diff-python (נתמך ב-Prism וב-Shiki עם תוסף).

def extract_blocks(text: str, lang: str | None = None):
    """Return the contents of every fenced block, optionally filtered by language."""
    return [m.group(3) for m in FENCE.finditer(text)

    Python
    from dataclasses import dataclass

@dataclass
class CodeBlock:
    code: str
    lang: str = "text"

    def to_markdown(self) -> str:          # GitHub, GitLab, Discord
        fence = "`" * max(3, longest_backtick_run(self.code) + 1)
        return f"{fence}{self.lang}\n{self.code}\n{fence}"

    def to_slack(self) -> dict:            # Block Kit
        return {"type": "rich_text", "elements": [{
            "type": "rich_text_preformatted",
            "elements": [{"type": "text", "text": self.code}]}]}

    def to_notion(self) -> dict:
        chunks = [self.code[i:i + 2000] for i in range(0, len(self.code), 2000)]
        return {"type": "code", "code": {
            "language": NOTION_LANGS.get(self.lang, "plain text"),
            "rich_text": [{"type": "text", "text": {"content": c}} for c in chunks]}}

def longest_backtick_run(s: str) -> int:
    import re
    return max((len(m) for m in re.findall(r"`+", s)), default=0)
