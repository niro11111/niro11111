    פרק 1

    היסודות שכולם מפספסים

    ב-Markdown יש שלוש דרכים להציג קוד. חשוב להבין את ההבדלים, כי כל השאר נבנה עליהם.

    1. קוד בתוך שורה (inline)

    עוטפים בגרש הפוך אחד (backtick). מתאים לשמות פונקציות, משתנים, פקודות קצרות ונתיבים.

    הריצו את `npm install` ואז ערכו את `config.json`.

    2. בלוק מגודר (fenced code block)

    שלושה גרשים הפוכים (או יותר) בשורה נפרדת, מיד אחריהם מזהה שפה, ושורת סגירה עם אותו תו. זו הדרך המומלצת כמעט תמיד.

    Markdown
    ```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

    אפשר להשתמש גם ב-tilde (~~~) במקום גרשים. זה שימושי כשהקוד עצמו מכיל גרשים הפוכים:

    ~~~bash
echo "the date is `date`"
~~~

    3. בלוק מוזח (indented)

    ארבעה רווחים או טאב בתחילת כל שורה. זו שיטה ישנה: אין בה מזהה שפה ולכן גם אין הדגשת תחביר, והיא נשברת בקלות בתוך רשימות. עדיף להימנע ממנה.

        for i in range(3):
        print(i)

    בלוקי diff

    שורה שמתחילה ב-+ נצבעת בירוק, שורה שמתחילה ב-- נצבעת באדום. זה מעולה לקודי ריוויו ולמדריכי שדרוג.

    ```diff
 function total(items) {
-  return items.reduce((a, b) => a + b);
+  return items.reduce((a, b) => a + b, 0);
 }
```

    ב-GitHub אפשר גם לשלב diff עם הדגשת שפה בעזרת המזהה diff-js או diff-python (נתמך ב-Prism וב-Shiki עם תוסף).

    בלוקי קוד בעבודה עם Claude ומודלי שפה

    מודלי שפה קוראים וכותבים Markdown באופן טבעי. כשמשתמשים בבלוקים נכון בפרומפט, התשובות מדויקות יותר וקל יותר לעבד אותן אוטומטית.

    1. הפרדה בין הוראות לנתונים

    עטפו קוד, לוגים וקבצים בבלוק עם שפה, כדי שהמודל ידע בדיוק איפה הם מתחילים ונגמרים:

    מצא את הבאג בפונקציה הבאה והסבר אותו במשפט אחד:

```python
def avg(xs):
    return sum(xs) / len(xs) - 1
```

הלוג מהריצה:

```text
AssertionError: expected 2.0, got 1.0
```

    2. בקשת פלט שקל לחלץ

    בקשו מהמודל להחזיר את התוצאה בבלוק אחד עם שפה מוגדרת, ואז חלצו אותו בקוד:

    Python
    import re, json

FENCE = re.compile(r"^(`{3,}|~{3,})[ \t]*(\w+)?[^\n]*\n(.*?)^\1[ \t]*$",
                   re.S | re.M)

def extract_blocks(text: str, lang: str | None = None):
    """Return the contents of every fenced block, optionally filtered by language."""
    return [m.group(3) for m in FENCE.finditer(text)
            if lang is None or (m.group(2) or "").lower() == lang]

data = json.loads(extract_blocks(reply, "json")[0])

    3. הגדר הסוגרת קיימת ואורכה לפחות כאורך הפותחת.
    4. הקוד ניתן להעתקה ולהרצה: בלי $ בבלוק bash, בלי גרשיים חכמים ובלי ... באמצע.
    5. בפקודה עם פלט משתמשים ב-console. בפקודה להעתקה משתמשים ב-bash.
    6. בלוק ארוך (מעל 30 שורות) מתקפל בתוך <details>, או שמקצרים אותו.
    7. שם קובץ (title) והדגשת שורות כשהכלי תומך בהם.
    8. אין סודות! מחליפים טוקנים ב-<YOUR_API_KEY>.
